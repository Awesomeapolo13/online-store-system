# Тестирование

Тесты располагаются в директории tests.

Далее они делятся на три категории:
- Integration;
- Unit;
- Functional.

По необходимости в директории Tools можно создавать классы
для упрощения тестирования.

Если тесты требуют создания записей в базе данных, они должны быть очищены после их завершения.
