# Удаление продукта из корзины

## Описание

1) Удаление происходит через HTTP POST запрос `/api/v1/cart/remove`. Тело запроса ниже:
```json
{
  "user_id": 1,
  "region": 52,
  "sup_code": "369428000000000"
}
```

Правила валидации:
- все параметры обязательные;
- код региона - число, должен быть в `App\Order\Domain\Enum\RegionCodeEnum`;
- sup_code - строка длинной 9 символов, содержит только числа.

2) Если у пользователя нет активной корзины, то отправляем команду на её создание, возвращаем ошибку 400 с просьбой повторить позже.
3) Если корзина есть, то удаляем товар из корзины и пересчитываем её полную стоимость.

## Требования

Удаление продукта реализовать через отдельную команду с обработчиком.
Для операций с корзиной использовать оптимистическую блокировку через функционала Doctrine ORM.

## Тестирование

Реализовать тесты удаления товара из корзины. 
Для этого понадобится база данных, поэтому очисти все данные после тестирования.
