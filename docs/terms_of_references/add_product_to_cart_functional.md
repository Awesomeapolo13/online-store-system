# Функционал добавления продукта в корзину

## Описание

1) Добавление товара в корзину происходит через эндпоинт `POST /api/v1/cart/add`. Тело запроса ниже:
```json
{
  "user_id": 1,
  "region": 52,
  "sup_code": "369428000000000",
  "quantity": 4,
  "order_date": "2026-06-26T13:00:00.000+03:00"
}
```

Правила валидации:
- все параметры обязательные;
- код региона - число, должен быть в `App\Order\Domain\Enum\RegionCodeEnum`;
- sup_code - строка длинной 9 символов, содердит только числа;
- quantity - целое число не меньше единицы.

2) Если корзина не найдена, то отправляем команду на её создание, возвращаем ошибку 400, с просьбой повторить ещё раз.
3) Если такой товар уже находится в корзине (есть товар с таким его sup_code), проверить его количество. Если количество не совпадает, то обновить его (после получения продукта) и пересчитать стоимость.
4) Если корзина найдена, отправляем запрос во внешний API продуктов.
Пример запроса: `GET /v1/product?sup_code=369428000000000&shop_number=0&region=52`
Ответ:
```json
{
  "success": true,
  "data": {
    "product": {
      "sup_code": "369428000000000",
      "price_per_item": 238.8,
      "is_available_for_order": false
    }
  }
}
```

5) Если продукт, полученный от API, доступен к заказу, рассчитываем его стоимость и добавляем в корзину. Возвращаем код об успешном добавлении товара в корзину.
6) Если продукт в корзине не удается получить с ошибкой `1001`, его надо удалить из корзины. Структура ошибки ниже.
```json
{
  "success": false,
  "data": {
    "error": {
      "code": "1001",
      "message": "No such product"
    }
  }
}
```

## Требования

Добавление продукта реализовать через отдельную команду с обработчиком.

Для связи с API продуктов создать интерфейс на уровне приложения модуля Order `App\Order\Application\Api\Product\ProductApiInterface`. В него добавить метод получения продукта, с входным и выходным ДТО.
Реализацию интерфейса поместить на уровень инфраструктуры `App\Order\Infrastructure\Http\Api\Product\SymfonyClientProductApi`.
Реализовать через компонент symfony/http-client (`Symfony\Contracts\HttpClient\HttpClientInterface`). Данные эндпоинта
Ответы API будут мокироваться через mockoon.

После реализации функционала и тестов необходимо выполнить статический анализ кода через cs-fixer, stan и deptrac.

## Тестирование

По итогу выполнения реализовать функциональные тесты добавления товара в корзину. При необходимости добавить конфигурацию mockoon для тестирования.
Для классов, вроде ассемблеров, реализовать юнит тесты.
