# Функционал установки параметров корзины

## Описание

1) Установка параметров корзины происходит через эндпоинт `POST /api/v1/cart/setup`. Тело запроса ниже:
```json
{
  "user_id": 1,
  "region": 52,
  "order_date": "2026-06-26T13:00:00.000+03:00",
  "is_delivery": false,
  "shop_id": 333
}
```

Правила валидации:
- параметры user_id, region, order_date, is_delivery являются обязательными;
- параметр shop_id является обязательным для заказа на самовывоз (когда `is_delivery = false`)
- код региона - число, должен быть в `App\Order\Domain\Enum\RegionCodeEnum`;
- order_date - самая ранняя дата - это через 2 часа от текущего времени.

2) Если корзина не найдена, то отправляем команду на её создание, возвращаем ошибку 400, с просьбой повторить ещё раз.
3) Если корзина есть, то отправляем команду на настройку корзины CartSetUpCommand.
4) После обработки команды отдаем корзину с измененными параметрам.

## Требования

Для настройки корзины создать отдельную команду и обработчик.
При создании команды обрати внимание на наличие объектов значений типа Type и OrderDate.
При изменении корзины используй оптимистическую блокировку (по аналогии с командой удаления товара из корзины).
После реализации функционала и тестов необходимо выполнить статический анализ кода через cs-fixer, stan и deptrac.

## Тестирование

Реализуй unit тесты для объектов значений, затронутых в задаче.
Реализуй тесты функционала настройки корзины.
Если был задет уже существующий функционал покрытый тестами внеси исправление в тесты этого функционала.
