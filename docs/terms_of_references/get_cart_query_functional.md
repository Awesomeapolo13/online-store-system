# Получение корзины

## Описание

1) Корзина пользователя получается посредством HTTP GET запроса `/api/v1/cart` с параметром user_id и региона.
2) Если у пользователя нет активной корзины, отправляем сообщение в очередь cart.command.create, пользователю возвращаем статус 202 с пустым телом.
3) Если корзина есть, то запрашиваем её через Query, выводим все данные корзины вместе с продуктами, кроме createdAt, updatedAt, version и deletedAt.

## Требования

1) Маппинг параметров запросов в свойства объектов должен быть реализован через функционал MapRequestPayload либо MapQueryString.
2) Валидация входных параметров должны быть описана в конфиге config/validator/validation.yaml.

## Тестирование

Если тесты требуют создания данных в базе данных необходимо после тестов очистить её от данных.
1) Напиши юнит тесты для объектов ассемблеров
2) Напиши функциональный тест для функционала получения корзины. Учти, что при отсутствии корзины она создается асинхронно, то есть необходим перезапрос для её получения. Так же учти что с одним и тем же user_id создать корзину нельзя.

Запрос для примера:
```shell
curl --request GET \
  --url 'http://localhost/api/v1/cart?user_id=77&region=52'
```
